# 团队周报洞察助手 · 作品集

面向管理者的智能工作汇报分析助手，基于 **Dify Workflow** 搭建。
把几名团队成员零散的周报，自动变成任务清单、风险评级、信息缺口与一份可交付的 Word 周报。

**在线预览**：https://<你的用户名>.github.io/<仓库名>/  ← 部署后把这一行改成真实地址

## 这个仓库里有什么

| 文件 | 说明 |
| --- | --- |
| `index.html` | 作品集展示页。单文件、零外部依赖，双击即可离线打开；页面内嵌了本项目的 Dify DSL，可在页脚一键下载 |

## 页面包含

- **价值说明**：团队周报「信息分散、风险滞后、向上汇报重复劳动」三个痛点与对应解法
- **核心能力**：周报归一化、任务拆解与状态判定、风险识别与分级、信息完整度体检、管理报告自动成稿
- **工作流拓扑**：9 个节点（4 个 LLM / 1 个代码 / 1 个模板 / 1 个工具），点击节点可查看类型、模型、变量映射与关键提示词
- **交互演示**：填入成员周报即可运行一遍完整流程，输出周报正文、结构化 JSON 与完整度评分
- **工程实现**：结构化输出 Schema、职责边界与防幻觉约束、模板聚合与变量传递、周报渲染规范

## 关于演示

页面中的交互演示为**纯前端规则引擎模拟**（离线运行、无需 API Key），用于展示交互流程与产出形态；
真实分析由 Dify 工作流中的 4 个 LLM 节点通过 JSON Schema 结构化输出完成。

## 本地查看

下载 `index.html` 后双击打开即可，无需服务器、无需联网。
